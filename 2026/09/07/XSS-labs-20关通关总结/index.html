XSS-labs 20关通关总结

发表于2026-09-07|更新于2026-09-07
|浏览量:

XSS-labs 是本地 phpstudy 环境的反射型 XSS专项靶场，闯关判定：靶场重写了 window.alert，只要触发 alert() 就自动跳转下一关。做完 SQL-labs 再来做这个，上手很快——很多关卡的思路本质就是”闭合原语句，插入 payload”。

这篇文章主要按防御手法把 20 关串一遍。

### 无过滤与属性注入（L1–L4）
L1：$_GET["name"] 直接 echo 出来，零过滤。<script>alert(1)</script> 直接过。

注意闭合后要有空格分隔新属性。

闭合 value 之后全是新属性，autofocus 自动聚焦触发 onfocus。

L10：三个 hidden 的 input，只有 t_sort 可控。利用 HTML 解析器对重复属性只取第一个，注入 type 覆盖 hidden，再补事件：

L11–L13：没有输入框提示，看源码发现注入点在 HTTP 头里——Referer（L11）、User-Agent（L12）、Cookie（L13），都没过滤且回显到前端。思路就是：真实场景下不知道源码，就把可能回显的头注入点挨个试。L13 只过滤了 <>，属性注入照样过。

### 防御演进复盘

防御手法 关卡 绕过思路
无过滤 L1 直接插 <script>
部分过滤（漏了属性点） L2 闭合 value
htmlspecialchars 默认模式 L3 单引号没转义，照样闭合
删除 <> L4、L13 属性注入不需要尖括号
黑名单但无 strtolower L6 大小写
单次 str_replace 置空 L7 双写
字面匹配协议名 L8、L9 HTML 实体编码 + // 注释骗检查
隐藏输入框 L10–L13 重复属性只取第一个；头注入挨个试
过滤空格/斜杠 L16 %0A 等空白符替代
### 总结
  1. XSS 的核心是上下文：同样的输入，在标签体、属性值、JS 字符串、URL 里，利用方式完全不同。先看输出点在哪，再想怎么闭合。
  2. 黑名单：大小写、双写、实体编码、空白符变体，多试几个。正确姿势是白名单 + 输出编码，或者直接用 React/Vue 这类自带转义的框架（课设里用过，原理待补）。
  3. 这个靶场与sql-lab相同教学性质很强，更像在告诉你”这里不过滤就有洞”。真实场景要自己 fuzz 找输出点。
    下一步：PortSwigger Web Security Academy 的 XSS 模块（30+ lab），补 DOM 型 XSS、CSP 绕过这些更深的方向。
